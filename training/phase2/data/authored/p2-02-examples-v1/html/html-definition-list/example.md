# Plex P2 example draft-html-definitions

## Request

Create a definition list for three keyboard shortcuts. Each shortcut is a term followed by a brief description.

## Solution

```html
<dl>
  <dt>Ctrl + S</dt>
  <dd>Save the current document.</dd>
  <dt>Ctrl + Z</dt>
  <dd>Undo the last change.</dd>
  <dt>Ctrl + F</dt>
  <dd>Find text in the current document.</dd>
</dl>
```
