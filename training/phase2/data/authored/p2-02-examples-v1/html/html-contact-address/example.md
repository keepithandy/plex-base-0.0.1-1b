# Plex P2 example draft-html-contact

## Request

Add a contact block with a support email link and a telephone link, using the semantic element intended for contact information.

## Solution

```html
<address>
  <a href="mailto:support@example.test">support@example.test</a>
  <a href="tel:+15550102020">+1 555 010 2020</a>
</address>
```
