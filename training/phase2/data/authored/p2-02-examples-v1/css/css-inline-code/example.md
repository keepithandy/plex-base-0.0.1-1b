# Plex P2 example draft-css-inline-code

## Request

Style .inline-code with a monospace font, a light gray background, a small rounded corner, and compact padding.

## Solution

```css
.inline-code {
  font-family: monospace;
  background: #f3f4f6;
  border-radius: 0.25rem;
  padding: 0.125rem 0.25rem;
}
```
