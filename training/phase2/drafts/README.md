`p2-02-authored-examples-v1.jsonl` contains nine Codex-authored examples that the repository owner approved on 2026-10-04 for inclusion in a new local P2 corpus. They contain no external source material. The companion [materializer](../materialize_authored_examples.py) creates grouped Markdown source files, and [dataset catalog v2](../dataset-sources.phase2-v2.json) records their approval and provenance. The existing P2-02 v2 data and tokenizer remain unchanged; the examples are included in the separate v3 corpus documented in the [build report](../../../docs/PHASE-2-DATASET-V3-REPORT.md).

The examples pair a short HTML, CSS, or JavaScript request with a solution and small expected-behavior notes. There are three examples per language, each assigned its own `splitGroupId` so the dataset builder keeps each request/solution pair together. `candidateSplit` records seed 51's group-stratified split: one of three groups per language goes to validation (about 33%), and the other two go to training. The dataset builder independently computes and verifies the assignment. The requests were checked against the 30 P2-01 development prompts; no exact request duplicates were found. The `smokeCases` remain review notes only; they are not included in the source files or benchmark, and they have not been executed.

The nine examples are included in the combined v3 corpus and its training-only-fitted tokenizer. The corpus has 36 training and 20 validation records; the aggregate token counts and hashes are recorded in the [v3 build report](../../../docs/PHASE-2-DATASET-V3-REPORT.md). Step-zero and the ten-minute trained checkpoint both scored 0/30 complete development tasks. The trained outputs were all truncated; the [data-mix review](../../../docs/PHASE-2-DATA-MIX-REVIEW.md) records that these six training-side authored examples contribute only 0.7% of v3 token positions.
